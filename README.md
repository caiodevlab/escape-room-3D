## 📖 Premissa

Você acorda trancado em uma sala misteriosa. Sem memórias. Sem pistas.

Ao redor, objetos que não fazem sentido. Puzzles que precisam ser resolvidos. Um cronômetro que não para.

A porta só abre quando todas as peças se encaixarem.

---

## 🎮 Features

- 🏠 Ambientes 3D imersivos com iluminação dinâmica
- 🧩 Puzzles lógicos e espaciais
- ⏱️ Sistema de cronômetro com limite de tempo
- 🎯 Sistema de hints progressivos
- 📦 Inventário de objetos coletados
- 🚪 Objetivo claro: resolver → escapar

## 🚀 Como rodar

### 1. Instale o Godot 4.x

Baixe em https://godotengine.org — é open source e gratuito.

### 2. Abra o projeto

```bash
# Abra o Godot Editor
godot --path escape-room-3D
# Ou abra pelo editor: Project → Open → selecione a pasta
```

### 3. Execute

No editor: ▶️ (botão Play) ou `F5`
